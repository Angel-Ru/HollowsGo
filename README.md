# HollowsGO Remastered
<img src="https://github.com/Angel-Ru/HollowsGo/blob/main/FLUTTER/hollows_go/lib/images/tutorial_screen/Pas_0.png" alt="LogoHollowsGoRemastered" width="400">

Created by **[Miquel Sansó](https://github.com/MiquelSanso)** · **[Àngel Rubio](https://github.com/Angel-Ru)** · **[Albert Galán](https://github.com/AlbertGalan)**

**HollowsGO Remastered** is a mobile video game combining gacha mechanics, real-time map exploration with enemy encounters, and turn-based combat. Developed with Flutter, Dart, and a custom Node.js API.
